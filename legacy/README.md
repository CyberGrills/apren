# Apren source archive

These files preserve the original food-platform implementation and historical generation scripts at commit 26d61a4aaf0ee87411b57df2ac94a5e5ad607e33. The original assets engine has been promoted to the active `services/apren-engine` service; the remaining legacy services, web source and generation scripts are outside the active npm workspaces and are not part of the 7even runtime. Do not run archived scripts as installation or migration steps.

The original README and package manifests are reference material. Use the repository root README for 7even setup. The complete original 486-file guide and 42-finding review are in docs/7even/legacy-review. Original service paths map to legacy/services, original web source to legacy/web-src, and root shell generators to legacy/scripts.
